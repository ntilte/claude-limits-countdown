# Limits countdown

Мод для Claude Code: над полем ввода видно, сколько осталось до сброса лимитов, сколько занято контекста, и можно отложить сообщения на потом. Работает в терминале и во вкладке Code приложения Claude Desktop.

```
   Сессия 92%  2 ч 49 мин        Неделя 58%  2 д 18 ч        Контекст 18%  176k из 1M
   ━━━━━━━━━━━━━━━━━━━━━━        ━━━━━━━━━━──────────        ━━━━────────────────────

   Отправлю через 2 ч: «Запусти тесты»              [Сейчас] [Отменить]
   Отправлю через 2 ч 50 мин: «Проверь сборку»      [Сейчас] [Отменить]

                         [Сжать]  [Отложить ещё]
```

- **Лимиты.** Время до сброса окна сессии (5 ч) и недели. От 75% цвет жёлтый, от 90% красный. Все открытые сессии показывают одни и те же свежие цифры.
- **Контекст.** Сколько занято окна. Кнопка «Сжать» запускает `/compact` после подтверждения.
- **Отложенные сообщения.** Напиши сообщение, нажми «Отложить» и выбери время: 30 мин, 1 ч, 2 ч, «после сброса» или своё («другое»: `90`, `2ч`, `1ч30м`). Можно отложить несколько подряд, каждое уйдёт в свой срок.

## Как работают отложенные сообщения

- «После сброса» — это когда снова можно писать: сброс окна сессии, а если неделя уже на 100%, то сброс недели.
- Если к сроку лимит исчерпан, сообщения ждут сброса и уходят по порядку.
- Сообщения уходят, пока приложение открыто. Очередь переживает перезапуск; если срок прошёл больше 10 минут назад, сообщение ждёт кнопки «Сейчас».
- Откладывается только текст, без картинок и файлов.

Команды: `/later 2ч текст`, `/later сброс текст`, `/later` — список, `/later отмена` — отменить все.

## Установка

```
/plugin install limits-countdown --marketplace ntilte/claude-limits-countdown
```

После установки перезапусти Claude. Обновление: `claude plugin update limits-countdown@ntd-local`.

## Разработка

```
claude plugin test .
claude plugin validate .
```

Нужен Claude Code с поддержкой модов (проверено на 2.1.328).
