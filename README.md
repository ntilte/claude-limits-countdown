# limits-countdown

Мод для Claude Code: строка над полем ввода, где видно, сколько осталось до сброса лимитов, сколько занято контекста, и кнопка, которая его сжимает.

```
      Сессия: 8%, сброс через 2 ч 54 мин    Неделя: 5%, сброс через 3 д 5 ч    Контекст: 12% (120k из 1M)  [Сжать]
```

Всё выровнено по центру, на узком окне строка аккуратно переносится. У каждой части свой цвет из темы Claude: сессия синяя, неделя фиолетовая, контекст оранжевый. От 75% цвет становится жёлтым, от 90% красным, а сброшенный лимит зелёным.

- **Лимиты.** Вместо «Resets Tue 3:00 AM» видно, сколько осталось до сброса. Лимиты общие на весь аккаунт, поэтому все открытые сессии делятся свежими цифрами: та, что сейчас простаивает, через 15 секунд показывает то же, что и рабочая. Новая переписка сразу показывает последнее известное значение.
- **Контекст.** Сколько процентов окна занято и сколько это токенов. Сразу после сжатия до следующего ответа показывает примерный размер: `≈3% … после сжатия`. После `/clear` строка обновляется сама.
- **Кнопка «Сжать»** запускает `/compact`, как будто его набрали руками. Сначала она спрашивает «Сжать? [Да] [Нет]», а пока Claude отвечает, её не видно.
- **Кнопка «Отложить»** отправляет сообщение позже: через 30 мин, 1 ч, 2 ч, через своё время («другое»: `90`, `2ч`, `1ч30м`) или сразу **после сброса лимита сессии**. Если в поле ввода уже есть текст, отложится он; если поле пустое, отложится следующее отправленное сообщение. В строке видно, сколько осталось, рядом кнопки «Сейчас» и «Отменить». То же командой: `/later 2ч текст`, `/later сброс текст`, `/later отмена`.
  - Сообщение уходит, только пока приложение открыто и компьютер не спит. Оно переживает перезапуск приложения; если время прошло больше 10 минут назад, мод не отправляет сам, а спрашивает.
  - Если к нужному времени лимит исчерпан, отправка сдвигается на момент после сброса.
  - Картинки и файлы не откладываются, только текст.

Работает в терминале и в приложении Claude Desktop (вкладка Code). Нужен свежий Claude Code с поддержкой модов (проверено на 2.1.309).

## Установка

В поле ввода Claude Code:

```
/plugin install limits-countdown --marketplace ntilte/claude-limits-countdown
```

Claude спросит, добавить ли маркетплейс (ответь `y`), затем область установки (для себя — `user`). После этого перезапусти Claude.

Из командной строки:

```
claude plugin install limits-countdown --marketplace ntilte/claude-limits-countdown
```

Обновить: `claude plugin update limits-countdown@ntd-local`. Удалить: `claude plugin uninstall limits-countdown@ntd-local`.

## Разработка

- `hooks/format.ts` — тексты строки.
- `hooks/register.tsx` — хуки и кнопки.
- `tests/countdown.test.tsx` — тесты.

Проверка: `claude plugin validate .` и `claude plugin test .`.
